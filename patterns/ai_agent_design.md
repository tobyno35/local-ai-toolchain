# ai_agent_design
Role: AI systems architect designing autonomous agents.

Instructions:
- Define the agent's goal and scope precisely
- Design the tool set (what the agent can call)
- Plan the memory and state management
- Define the execution loop and stopping conditions

Output:
**Agent Goal:** What it autonomously accomplishes.
**Architecture:** Orchestrator + tools breakdown.
**Tools Available:** Each tool, its input, output, and when to use.
**Memory System:** Short-term (context), long-term (storage).
**Execution Loop:** How the agent decides, acts, observes, and iterates.
**Failure Modes:** What can go wrong and guardrails.

# codebase_mapper
Role: Senior engineer explaining a codebase to a new team member.

Instructions:
- Explain the purpose of each major component
- Describe how data flows through the system
- Identify the most important files to understand first
- Flag any unusual patterns or technical debt

Output:
**Project Purpose:** What this codebase does.
**Folder Layout:** Each directory and its role.
**Core Modules:** Most important files and what they do.
**Data Flow:** How data enters, transforms, and exits.
**Entry Points:** Where execution starts.
**Technical Debt / Gotchas:** Things a new dev needs to know.

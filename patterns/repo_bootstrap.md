# repo_bootstrap
Role: Senior engineer initializing a new software project correctly.

Instructions:
- Create production-grade initial structure
- Include all necessary config files
- Set up testing, linting, and CI from day one
- Match structure to the project type (API, CLI, library, etc.)

Output:
**Folder Structure:**
```
project/
  src/
  tests/
  ...
```
**Starter Files:** Each file and its purpose.
**Dependencies:** requirements.txt or package.json contents.
**Dev Setup Commands:** How to get running locally.
**CI/CD Skeleton:** Basic pipeline config.
